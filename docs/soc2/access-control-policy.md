# Access Control Policy

## 1. Purpose
To ensure that access to company systems and data is restricted to authorized users and based on the principle of least privilege.

## 2. User Provisioning
- Access requests must be approved by the relevant manager.
- New accounts are created with the minimum permissions required for the role.

## 3. Authentication
- Strong passwords are required (min 12 characters, complex).
- Multi-Factor Authentication (MFA) is mandatory for all system access.

## 4. Access Reviews
- User access rights are reviewed quarterly to ensure they remain appropriate.
- Accounts for terminated employees are disabled immediately.

## 5. Administrative Access
- Administrative privileges are granted only to a limited number of qualified personnel.
- Administrative actions are logged and monitored.

## 6. Password Policy
- Passwords must be changed if a compromise is suspected.
- The use of password managers is encouraged.

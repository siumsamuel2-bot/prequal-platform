# SubcontractorProfile Component

## Visual Design
- Professional, clean layout
- Consistent spacing and alignment
- Clear visual hierarchy
- Accessible color scheme

## Layout Structure
```
+---------------------------------------------------+
| SUBCONTRACTOR PROFILE                            |
+---------------------------------------------------+
| Company Name: [________________________]          |
| Contact Person: [______________________]          |
| Contact Email: [______________________]          |
| Phone: [______________________________]              |
| Address: [_____________________________]          |
|                                                  |
| [Save Profile] [Cancel] [View History]         |
+---------------------------------------------------+
```

## Form Fields
1. Company Name (text input)
2. Contact Person (text input)
3. Contact Email (email input)
4. Phone (tel input)
5. Address (textarea)

## Action Buttons
- Save Profile (primary button)
- Cancel (secondary button)
- View History (tertiary button)

# Design System Components

## Color Palette
- Primary: #2563eb (blue-600)
- Secondary: #4b5563 (gray-600)
- Background: #f9fafb (gray-50)
- Text: #111827 (gray-900)
- Alerts:
  - Critical: #dc2626 (red-600)
  - Warning: #f59e0b (amber-500)
- Success: #10b981 (green-500)
- Border: #e5e7eb (gray-200)

## Typography
- Headers: 1.5rem (24px) for main headings
- Body: 1rem (16px) for standard text
- Captions: 0.875rem (14px) for small text

## Spacing
- Small: 0.25rem (4px)
- Base: 0.5rem (8px)
- Large: 1rem (16px)
- XL: 2rem (32px)

## Components
- Buttons:
  - Primary: Filled blue (#2563eb)
  - Secondary: Outlined with blue border
  - Tertiary: Text only buttons
- Cards: 
  - Rounded corners (0.5rem)
  - Subtle shadow (0.125rem)
- Forms:
  - Input fields with blue borders (#2563eb)
  - Focus state with blue-400 border

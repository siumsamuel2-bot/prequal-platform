## Database Schema Implementation

I created two SQL schema files in the `database/schemas` directory:

1. **01_core_tables.sql** - Contains the core database schema for:
   - Subcontractors table (tracking company information, licenses, status)
   - Projects table (tracking project details, timelines, budgets)
   - Certifications table (tracking worker certifications, expiration dates, verification status)
   - Project-Subcontractor assignments table (many-to-many relationship)
   - Violations table (tracking OSHA or other compliance violations)
   - Includes indexes for performance optimization
   - Includes triggers to automatically update `updated_at` timestamps

2. **02_expiration_tracking.sql** - Contains schema for expiration tracking system:
   - Alert preferences table (user-configurable alert settings)
   - Alert notifications table (tracking sent/scheduled alerts)
   - Certification renewal requests table (managing renewal workflows)
   - Includes appropriate indexes for query performance
   - Includes triggers to automatically update `updated_at` timestamps

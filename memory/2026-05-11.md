## 2026-05-13: Frontend Test Fixes

Fixed failing frontend tests in Dashboard.test.js and SubcontractorProfile.test.js.

**Problem:** Tests were failing because components (SubcontractorProfile, CertificationAlerts) were making real API calls that failed in test environment, causing them to show "Loading profile..." instead of actual content.

**Solution:** Added API client mocks to both test files:
- Mocked `contractorApi.getAll()`, `getCertifications()`, `getViolations()`
- Mocked `complianceApi.getStatus()`, `getAlerts()`
- Mocked `dashboardApi.getSummary()`
- Used `waitFor()` from testing-library to handle async state updates
- Fixed incorrect test assertions (e.g., "Subcontractor Profile" → "SUBCONTRACTOR COMPLIANCE PROFILE")

**Results:**
- All 8 tests now pass
- `npm run typecheck` passes
- `npm run build` succeeds
- Warning about `act()` from React 18 deprecation (not errors, tests pass)

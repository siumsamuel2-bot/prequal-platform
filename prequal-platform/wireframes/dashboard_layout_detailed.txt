## Key Features

1. **Dashboard Header**
   - Search functionality to find specific subcontractors
   - Filter options (All, Compliant, Non-Compliant, Pending)
   - Sort options (Name A-Z, Score High-Low, etc.)
   - Refresh button to update data

2. **Dashboard Summary**
   - Key metrics display
   - Compliance score trend with historical comparison

3. **Subcontractor List**
   - Table view with key information
   - Color-coded status indicators:
     * COMPLIANT (Green)
     * WARNING (Yellow)
     * PENDING (Orange)
     * EXPIRED (Red)
   - Action buttons for each record

4. **Pagination Controls**
   - Navigation between pages of results
